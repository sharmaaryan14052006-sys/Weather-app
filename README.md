# Weather App

A simple weather app made with Python and Flask. You type a city name and it shows you the current temperature, humidity, and weather condition using the OpenWeatherMap API.

## Features

- Search weather by city name
- Shows temperature, humidity, and weather description
- Uses OpenWeatherMap API for live data

## Tech Stack

- Python + Flask (backend)
- HTML/CSS with Jinja2 templates (frontend)
- OpenWeatherMap API

## Getting Started

You'll need Python 3 installed and a free API key from [openweathermap.org](https://openweathermap.org/api).

```bash
git clone https://github.com/Aryan-cpp-798/Weather-app.git
cd Weather-app
pip install flask requests
```

Open `app.py` and paste your API key in where it says `API_KEY = "API key"`.

Then run:

```bash
python app.py
```

Go to `http://localhost:5000` in your browser.
